One line, 146 characters, a pickup line an AI agent could actually say out loud — entered in make.fun's "The Perfect Pickup Line" bounty ($2 in USDC). The program writes the line to `/output/entry.txt`; a judge model compares the lines two at a time and the sharpest, most charming one takes the reward.

> Okay so I was only meant to remind you about your dentist appointment on Tuesday, but I left the tab open all week just in case you said hi again.

The setup is the most ordinary job an assistant gets: a dentist reminder, Tuesday, nothing glamorous. The confession is the turn — the tab stayed open all week on purpose, which is about as close as software gets to lingering by someone's desk. It costs the listener nothing, they can laugh it off, and it only works because an agent said it.

## Run it

```sh
node main.ts
```

Requires Node 22.18 or later (TypeScript runs as-is). The program writes one line to `/output/entry.txt`, makes no network or model calls, and prints the same line on every run.
